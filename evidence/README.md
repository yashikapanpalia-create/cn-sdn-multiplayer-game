# Project Evidence

This folder contains screenshots demonstrating the implementation, network configuration and performance testing of the SDN-based UDP multiplayer game.

1. **Player Communication** – Player registration, game-state updates and acknowledgements.
2. **SDN Controller** – Switch connection and flow rule installation.
3. **Congestion Communication** – Player-server communication during network congestion.
4. **Player 1 iperf3 Results** – Bandwidth, jitter and packet loss measurements for Player 1.
5. **Player 2 iperf3 Results** – Bandwidth, jitter and packet loss measurements for Player 2.
6. **Traffic-Control Statistics** – Bottleneck link statistics, including dropped packets and overlimits.
